# Руководство пользователя
## 1. Назначение программы
Приложение предназначено для локального трекинга задач.
## 2. Запуск
Для запуска перейдите в папку src/TaskTracker и выполните команду dotnet run.
## 3. Основные возможности
Пользователь может добавлять новые задачи, просматривать текущий список и удалять завершенные.
## 4. Порядок работы
После запуска приложения следуйте подсказкам текстового меню для навигации.
## 5. Ограничения
- Данные не синхронизируются с облаком и хранятся только на текущем устройстве.
- Отсутствует многопользовательский режим.
- Нет графического интерфейса (только консоль).
