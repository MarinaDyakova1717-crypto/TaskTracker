Поддерживаемая средаВеб-интерфейс должен стабильно работать в последних версиях Mozilla Firefox и популярных браузерах на базе Chromium (Google Chrome, Edge).   2. Работа с вкладкамиПользователь должен иметь возможность работать с приложением в нескольких вкладках одновременно без потери данных и сбоев.   3. Всплывающие окна (Pop-up)Важные функции приложения не должны открываться исключительно во всплывающих окнах, так как браузер может автоматически их заблокировать.   4. Файлы CookieПриложение должно обрабатывать ситуации, когда сторонние файлы cookie заблокированы пользователем, и не ломаться из-за этого.   5. АвторизацияФорма входа в приложение должна быть стандартной, чтобы корректно работать со встроенными в браузер менеджерами паролей.   6. Разрешения сайтовВеб-версия не должна требовать доступ к камере или геолокации без явной необходимости для конкретной задачи.   7. Уведомления
