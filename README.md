# TaskTracker
## Описание
Консольный трекер задач для управления временем. Разработан для демонстрации навыков администрирования репозитория. Тип приложения — консольная утилита.
## Используемые технологии
- C#
- .NET 8
- Git
## Требования
Для разработки и запуска проекта требуется .NET 8 SDK.
## Структура проекта
TaskTracker_AuditProject/
├── src/
│   └── TaskTracker/
├── docs/
├── config/
├── README.md
├── CHANGELOG.md
└── .gitignore
## Запуск
1. Установить необходимую версию .NET SDK.
2. Открыть терминал в корневом каталоге проекта.
3. Перейти в:
cd src/TaskTracker
4. Восстановить зависимости:
dotnet restore
5. Запустить:
dotnet run
## Основные возможности
- Управление списком задач через консольный интерфейс.
